# Support

Report bugs or request features in
[GitHub Issues](https://github.com/mohi-devhub/maritimefs/issues).
Include your MaritimeFS version, editor version, operating system, reproduction
steps, and a sanitized error. Describe whether the issue concerns Agents or
Computers; MaritimeFS currently integrates only Agents.

Never include API keys, environment files, sensitive remote files, or raw logs
containing credentials. If you suspect a credential leak, revoke it through
Maritime before sharing a report. Do not post security-sensitive details publicly.

For a private security report, use the repository's **Security → Report a
vulnerability** option if enabled. If unavailable, file an issue requesting a
private contact without including the vulnerability or any secret.

This is an independent community project. For Maritime account, infrastructure,
or billing problems, use Maritime's own support channels. Pre-release feedback is
welcome; no response-time or compatibility guarantee is offered.
