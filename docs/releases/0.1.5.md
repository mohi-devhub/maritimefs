# MaritimeFS 0.1.5

This pre-release adds a playable demo to the README and makes setup easier to follow. Runtime behavior is unchanged from 0.1.2.

MaritimeFS lets you browse and edit an agent's persistent volume in VS Code Explorer, run one-shot commands, inspect historical logs, and manage agent lifecycle. It requires desktop VS Code 1.105 or newer, an existing Maritime agent, and a suitable personal API key.

Saves use best-effort conflict detection without atomic conditional writes. Files are limited to 8 MiB, external changes require refresh, and remote operations depend on Maritime response time. This virtual filesystem does not provide an interactive shell or Remote SSH environment. Cursor and Windows have not been verified for this pre-release.

MaritimeFS is an independent MIT-licensed community extension, unaffiliated with Maritime. Do not include credentials or sensitive logs in issue reports.
