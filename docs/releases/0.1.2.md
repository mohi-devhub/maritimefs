# MaritimeFS 0.1.2

MaritimeFS 0.1.2 is the first [Visual Studio Marketplace pre-release](https://marketplace.visualstudio.com/items?itemName=mohi-devhub.maritimefs).

It lets you browse and edit a Maritime agent's persistent volume in the VS Code Explorer, run one-shot commands, inspect historical logs, and manage agent lifecycle. This version adds pre-release packaging and verification; runtime behavior is unchanged from 0.1.1. The production package uses the Maritime SDK and VS Code SecretStorage, with no simulation backend.

Requires desktop VS Code 1.105 or newer, an existing Maritime agent, and a suitable personal API key. Saved keys can restore within the same VS Code profile; agent workspaces must be reopened explicitly after a restart.

Saves use best-effort conflict detection without atomic conditional writes. Files are limited to 8 MiB, external changes require refresh, and remote operations depend on Maritime response time. This virtual filesystem does not provide an interactive shell or Remote SSH environment. Cursor and Windows have not been verified for this pre-release.

MaritimeFS is an independent MIT-licensed community extension, unaffiliated with Maritime. Do not include credentials or sensitive logs in issue reports.
